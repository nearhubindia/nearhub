# Play Console Screenshot Pack

This folder contains a ready-to-shoot content pack for Play Console screenshots.

## Required sets

1. Phone screenshots (portrait)
2. 7-inch tablet screenshots
3. 10-inch tablet screenshots

## Recommended export sizes

- Phone: 1080x1920 (or 1242x2208)
- 7-inch tablet: 1200x1920
- 10-inch tablet: 1600x2560

## Files in this folder

- `shot-list.md`: exact scenes to capture
- `mock-data.json`: realistic UI data to populate app screens
- `overlay-text.md`: optional marketing text overlays for each screenshot

## Notes

- Keep branding consistent with app colors and typography.
- Avoid showing debug/dev labels.
- Use the same account across all screenshots for consistency.
