# Play Console Screenshot Layout Spec (Figma/Canva Ready)

This spec is designed for fast production of Play Store screenshots for:
- Phone
- 7-inch tablet
- 10-inch tablet

## 1) Frame Setup

Create these frame sizes:

- Phone portrait: `1080 x 1920`
- 7-inch tablet portrait: `1200 x 1920`
- 10-inch tablet portrait: `1600 x 2560`

Use sRGB color profile.
Export as PNG.

## 2) Master Grid and Safe Areas

Use a shared composition system across all frames.

- Outer margin: 48 px (phone), 64 px (7-inch), 88 px (10-inch)
- Top safe zone for headline: first 22% of frame height
- Device mockup area: middle 63% of frame height
- Optional footer/support line: bottom 15% of frame height

Keep all important text inside safe margins.

## 3) Typography

Recommended:
- Font family: Geist / Poppins / Manrope
- Headline weight: 700
- Subtitle weight: 500

Suggested sizes:
- Phone: H1 58-66 px, subtitle 28-34 px
- 7-inch: H1 64-72 px, subtitle 32-38 px
- 10-inch: H1 84-96 px, subtitle 40-48 px

## 4) Screenshot Compositions

Create 8 final assets:

1. Phone - Home Feed
- Headline: `Find what you need nearby`

2. Phone - Listing Details
- Headline: `Verified sellers. Better deals.`

3. Phone - Create Listing
- Headline: `Post in under 60 seconds`

4. Phone - Chat
- Headline: `Negotiate safely in-app`

5. Phone - My Listings / Profile
- Headline: `Track views and leads`

6. 7-inch Tablet - Feed + Filters
- Headline: `Smarter search on a bigger screen`

7. 10-inch Tablet - Seller Dashboard
- Headline: `Grow faster with NearHub`

8. 10-inch Tablet - Plans / Boost
- Headline: `Boost visibility, close faster`

## 5) Export

Filename format:
- `01-phone-home.png`
- `02-phone-detail.png`
- `03-phone-create.png`
- `04-phone-chat.png`
- `05-phone-profile.png`
- `06-tab7-filters.png`
- `07-tab10-dashboard.png`
- `08-tab10-plans.png`
